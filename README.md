# Vaishnavi Fasale — Portfolio

Responsive personal portfolio inspired by the clean structure and presentation style of modern developer portfolios such as Ravi Khokle's site, while using original content and design.

## Stack
HTML5, CSS3, Bootstrap 5, Bootstrap Icons.

## Before publishing
- Replace `your-email@example.com` with your actual email.
- Add your resume as `resume.pdf`.
- Add correct GitHub links for projects when those repositories are ready.
- Add a professional profile photo later if you want one.

## Run
Open `index.html`.

## GitHub Pages
Push the folder to a GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from branch → `main` → `/ (root)`.
